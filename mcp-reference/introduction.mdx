Mallary exposes a remote MCP server over Streamable HTTP for public API parity.

ChatGPT uses a smaller OAuth-only MCP endpoint at `/mcp/openai`. It includes the tools needed to upload social images, publish posts, reply to comments, and read results. The main `/mcp` endpoint keeps the full Mallary tool set for other MCP clients.

## Base URL

```text
https://mallary.ai
```

## MCP Endpoint

Mallary serves MCP at:

```text
/mcp
```

Supported methods:

- `POST /mcp`
- `GET /mcp`
- `DELETE /mcp`

ChatGPT uses the same methods at:

```text
/mcp/openai
```

## What You Can Do

Mallary MCP gives MCP clients the same publishing surface as the public Mallary API. This surface includes:

- posting and media uploads
- comment listing and comment replies
- analytics
- connected platform listing and platform disconnects
- webhook management
