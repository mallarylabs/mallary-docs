---
title: "Reply to Comment"
description: "Reply to a specific comment on a post that you published using Mallary."
openapi: "POST /api/v1/comments/reply"
---

Available on all plans.

Mallary posts the exact `message` you send. Your AI agent or script must write the reply.

For a LinkedIn Page post, Mallary sends the reply as the Page you selected. LinkedIn may ask you to reconnect once so Mallary can reply as that Page.
