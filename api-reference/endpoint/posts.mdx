---
title: "List Posts"
description: "List grouped multi-platform posts with per-platform results, retries, warnings, and capabilities."
openapi: "GET /api/v1/posts"
---

Use `profile_id` to list grouped posts for a non-default connection profile. Omit it to list the default profile.

Each post includes per-platform `results`. Completed platform results include `platform_post_id` and `platform_post_url` when the platform returned or exposed those values.
