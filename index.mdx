## 2. Choose your integration path

Mallary has several ways to connect, and all of them reach the same underlying system.
Use the ChatGPT plugin or Claude connector for a simple chat. Use the API for full control, or MCP for AI agents. Use the CLI for shell scripts, n8n or Make for workflow automation, or the dashboard for no-code publishing. You can switch between them, or combine them, at any time.
