## 2. Choose your integration path

Mallary has five integration layers, and all of them reach the same underlying system.
Use the API for full control, or MCP for AI agents. Use the CLI for shell scripts, n8n for workflow automation, or the dashboard for no-code publishing. You can switch between layers, or combine them, at any time.
