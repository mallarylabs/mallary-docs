## Install

```bash
npx skills add mallarylabs/mallary-agent
```

Or download <a href="https://github.com/mallarylabs/mallary-agent/blob/main/SKILL.md">SKILL.md</a> to upload to Claude or any AI tool manually.

## What's included

The skill teaches your AI agent how to use the Mallary API. It covers endpoint selection, parameter usage, pagination, uploads, and platform-specific rules. These rules cover all 10 supported platforms, including TikTok, Instagram, YouTube, LinkedIn, Twitter/X, Reddit, and Facebook.

| When you say | What the skill does                           |
| -------- | ------------------------------------- |
| "post this video to all my accounts"     | Sends the video and the publishing intent to the Mallary CLI. The CLI handles the upload, the queue, platform-specific posting, retries, status, and reporting. |
| "Schedule these 2 video posts for tomorrow at 9am and 3pm."      | Resolves "tomorrow at 9am and 3pm" into exact timestamps. Uploads the two videos to the Mallary CDN. Creates two scheduled jobs through the Mallary API or MCP. A Mallary worker publishes them later, and tracks status, retries, and failures. |
| "How did yesterday's post do?" | Resolves "yesterday" to the correct date range. Authenticates through the Mallary API or MCP. Finds the posts from that day. Reads the available performance data, such as views, likes, comments, shares, clicks, and platform-specific metrics. |
| "Reply to everyone who commented on my launch post." | Calls the Mallary comment-list endpoint or tool for the published post. Writes each reply in the user's voice. Sends the exact reply text through the comment-reply endpoint or tool. |

## Skill vs MCP
The MCP server gives your AI agent direct API access. It can call Mallary endpoints on your behalf. The skill teaches the agent best practices for those APIs: which endpoint to pick, how to upload files, and the platform-specific rules. Use the skill and the MCP server together, or use each one alone.

## Comment engagement

Agents can use Mallary for post-publication engagement without browser automation:

1. Find the Mallary `post_id`/job ID from the post list or job lookup.
2. Call `GET /api/v1/comments` or MCP `mallary_list_comments`.
3. Write the reply in the user's voice.
4. Call `POST /api/v1/comments/reply` or MCP `mallary_reply_to_comment` with the exact reply text.

Comment listing and supplied replies are available on all plans for Facebook, Instagram, Threads, LinkedIn, X, and YouTube.
