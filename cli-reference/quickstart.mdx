---
title: "Quickstart"
description: "Get started with health checks, uploads, posting, connected-platform listing, and job inspection."
---

## Health Check

```bash
mallary health
```

## Upload Local Media

```bash
mallary upload ./launch.mp4
```

## Create a Post

```bash
mallary posts create \
  --message "Check out my new product video!" \
  --platform facebook \
  --platform instagram \
  --profile-id AbC123xYz90 \
  --media ./launch.mp4
```

## List Posts

```bash
mallary posts list
```

## Inspect a Job

```bash
mallary jobs get 123
```

## List Connected Platforms

```bash
mallary platforms list
mallary profiles list
```

Use `mallary profiles list` to find the random public profile ID, then pass `--profile-id` when you want to post from, list, or disconnect a non-default Mallary profile.
