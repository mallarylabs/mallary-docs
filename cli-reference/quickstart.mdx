## Health Check

```bash
mallary health
```

## Upload Local Media

```bash
mallary upload ./launch.mp4
```

## Create a Post

```bash
mallary posts create \
  --message "Check out my new product video!" \
  --platform facebook \
  --platform instagram \
  --profile-id AbC123xYz90 \
  --media ./launch.mp4 \
  --thumbnail ./launch-cover.jpg
```

## List Posts

```bash
mallary posts list
```

## Read a Job

```bash
mallary jobs get 123
```

After publishing, job output includes `platform_post_id` and `platform_post_url` when the platform returns or exposes them.

## List Connected Platforms

```bash
mallary platforms list
```

## List Your Profiles within Mallary

Profiles group your social media accounts. Create one profile for each of your businesses. Then connect the social media accounts of that business inside its profile. If you do not send a `profile_id`, Mallary uses your default profile.

Each profile has a random public ID, such as AbC123xYz90. Use that ID as `profile_id` in API, MCP, and CLI requests.

Omit `profile_id` on publishing and reporting endpoints to use the default profile. Send `profile_id` when you want to target a non-default profile.

```bash
mallary profiles list
```
