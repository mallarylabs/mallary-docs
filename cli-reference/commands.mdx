## Authentication

```bash
mallary auth login
mallary auth login --scope publish
mallary auth status
mallary auth logout
```

OAuth login starts with read-only access. A broader scope grants a capability but does not approve a particular state-changing command.

## Health

```bash
mallary health
mallary health --json
```

## Upload

```bash
mallary upload ./image.png
mallary upload ./image.png ./video.mp4 --json
```

This command:

1. calls Mallary to create a presigned upload URL
2. uploads the local bytes for you
3. returns the final Mallary media URL

Use the returned URL as `media[].url` for media, or as `media[].thumbnail_url` for video thumbnails in file-mode post payloads.

## Posts

```bash
mallary posts list
mallary posts list --profile-id AbC123xYz90
mallary posts list --page 2 --per-page 25 --json
mallary posts delete 123
```

After publishing, grouped post results include the per-platform post IDs and public post URLs that the provider makes available.

## Comments

```bash
mallary comments list --post-id 123
mallary comments list --post-id 123 --platform instagram --limit 50 --json
mallary comments reply --post-id 123 --comment-id "1789..." --message "Thanks for checking this out."
```

Comments commands are available on all plans. They list comments from Mallary-published posts and post the exact reply text you provide.

## Jobs

```bash
mallary jobs get 123
mallary jobs get 123 --json
```

Completed jobs include `platform_post_id` and `platform_post_url` in JSON mode, and print `Post ID` / `Post URL` in normal output when available.

## Webhooks

List:

```bash
mallary webhooks list
```

Create:

```bash
mallary webhooks create \
  --url https://example.com/mallary \
  --event post.published \
  --event post.failed
```

Delete:

```bash
mallary webhooks delete 12
```

## Settings
